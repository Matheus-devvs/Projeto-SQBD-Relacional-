# Diagnóstico Operacional & Engenharia de Dados com SQLite, Excel e Power BI

* Sobre o Projeto
Desenvolvimento de uma arquitetura de dados relacional no SQLite para simular um cenário real de e-commerce. O projeto abrange desde a modelagem física do banco de dados (DDL/DML com integridade referencial) até o diagnóstico financeiro de perdas de faturamento na camada executiva (Power BI).

* Tecnologias Utilizadas:
- Banco de Dados: SQLite (DDL/DML, PK/FK)
- ETL & Tratamento: Power Query / Excel
- Visualização: Power BI (Layout Grid & Storytelling Executivo)

* Problema de Negócio & Insights Diagnosticados:
Durante a auditoria de faturamento bruto vs. líquido, identificou-se que o canal TikTok liderava um cenário de crise operacional:
- Perda Total: R$ 24.000,00 em itens cancelados.
- Taxa de Cancelamento: 83% dos pedidos efetuados no canal.
