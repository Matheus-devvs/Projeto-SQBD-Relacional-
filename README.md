# Diagnóstico Operacional & Engenharia de Dados com SQLite, Excel e Power BI


Sobre o Projeto: Desenvolvimento de uma arquitetura de dados relacional no SQLite para simular um cenário real de e-commerce. O projeto abrange desde a modelagem física do banco de dados (DDL/DML com integridade referencial) até o diagnóstico financeiro de perdas de faturamento na camada executiva (Power BI).

Tecnologias Utilizadas: Banco de Dados (SQLite com DDL/DML, PK/FK), ETL e Tratamento (Power Query / Excel) e Visualização (Power BI com Layout Grid & Storytelling Executivo).

Problema de Negócio & Insights Diagnosticados: Durante a auditoria de faturamento bruto vs. líquido, identificou-se que o canal TikTok liderava um cenário de crise operacional, interações com 74 ocorrências (49% do total), mas sofre com uma taxa crítica de cancelamento de 83,04%, acumulando uma perda de R$ 27.320,20 em itens cancelados (contra apenas 6,38% de pedidos concluídos).
